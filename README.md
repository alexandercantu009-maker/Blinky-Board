# Blinky Board – Cybertruck Edition

A blinky board I designed in KiCad for Hack Club Twisted. A 555 timer clocks a CD4017 counter, which lights 10 LEDs one after another in a row along the truck's body. The board is shaped like a Cybertruck, with wheels and window art on the silkscreen.

<img src="Blinky%20Board.png" alt="3D view of the Blinky Board" width="700">

## Parts
- NE555P timer
- CD4017 decade counter
- 10 LEDs (5 mm)
- 2 resistors, 2 capacitors, 1 potentiometer (speed control)
- 2-pin header for power

## Files
- `Blinky Board.kicad_pro`, `.kicad_sch`, `.kicad_pcb`: KiCad project, schematic, and PCB
- `Gerbers.zip`: manufacturing files
- `Blinky Board.png`: 3D render
